<details>
<summary><b>AI-Powered Interview Preparation Platform</b></summary>

<br/>

A full-stack MERN platform that analyzes a candidate's resume and a job description with the Google Gemini API to generate personalized technical and behavioral interview questions, skill-gap analysis, and a preparation roadmap.

| | |
|:--|:--|
| **Stack** | React.js, Node.js, Express.js, MongoDB, Google Gemini AI, JWT |
| **Scale** | Full-stack MERN application covering question generation, skill-gap analysis, and roadmap creation |
| **Performance** | Automatic retry with exponential backoff to handle Gemini API rate limits under load |
| **Security** | JWT authentication with httpOnly cookies and bcrypt password hashing |
| **Impact** | Personalized interview preparation, plus an AI resume-tailoring feature that exports PDFs via Puppeteer |
| **Repository** | [View on GitHub](https://github.com/piyushgupta786/Interview-Prep-Ai) |

Prompts use structured JSON schemas instead of free-form text parsing, which keeps AI output predictable and easy to render in the UI.
